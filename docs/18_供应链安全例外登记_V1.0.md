# AI Wardrobe 供应链安全例外登记 V1.0

更新时间：2026-07-26

## 门禁

- Python 生产依赖由锁文件固定，并在 CI 使用 `pip-audit` 检查已知漏洞。
- 小程序生产依赖由 `pnpm-lock.yaml` 固定，CI 对 High 及以上漏洞失败。
- 第三方 GitHub Actions 必须固定到完整 Commit SHA，版本标签只作为注释。
- 所有直接和可兼容的传递依赖漏洞必须升级或使用精确版本覆盖，不接受宽泛忽略。

## 临时例外：GHSA-fx2h-pf6j-xcff

| 项目 | 内容 |
|---|---|
| 依赖 | Vite 5.4.21（DCloud UniApp 工具链固定 Peer 为 Vite 5） |
| 漏洞边界 | Windows 上开发服务器 `server.fs.deny` 的路径绕过 |
| 当前暴露 | 项目开发与 CI 为 macOS/Linux；封测交付物是微信小程序静态产物，不运行或暴露 Vite 开发服务器 |
| 补偿控制 | Vite 升至 5 系列最新修复版本；CI 仅对该 GHSA 精确忽略；其他 High 继续失败 |
| Owner | 前端负责人 |
| 到期条件 | DCloud 发布兼容 Vite 6.4.3+ 的工具链后立即移除 |
| 最迟复核 | 2026-08-09 |

例外不得扩展到 Windows 开发服务器对外监听场景。若开发环境变更为 Windows，
必须在变更前升级 DCloud/Vite 或停止使用该开发服务器。
