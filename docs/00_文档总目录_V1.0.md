# AI Wardrobe 中国版核心研发文档总目录 V1.1

## 项目定义
AI Wardrobe 是一个以微信小程序为入口，围绕 Personal Wardrobe Graph、Personal Style Graph、Personal Decision Graph 构建的 Personal Style Agent。

核心价值链：
现实穿搭 → AI 看懂 → 最小优化 → 建立数字衣橱 → 记录真实选择 → 学习个人偏好 → 持续穿搭决策 → 必要时辅助购物决策。

## 项目阶段
### P0a：Infrastructure Foundation
基础工程、用户身份、Asset、AI Job、Outbox + Offline AI Eval 双轨并行。

### P0b：AI Experience
AI 穿搭诊断、Minimal Change Optimization、Before/After、微信分享、A/B 投票。

### P0 Hardening
Bug 修复、日志补齐、Prompt Version 化、成本复盘、备份演练、30～50 人封闭测试。

### P0.5：建库与数字空间
渐进式衣橱、商品链接快速入库、Garment Digital Twin、Display Asset、最小 Visual Shoe Wall。

### P1：Personal Stylist
Outfit Agent、Look、Wear Event、Preference Signal、Style Graph、完整 Visual Shoe Cabinet。

### P1.5：长期留存
Visual Wardrobe、Laundry、Weekly Planning、Old Clothes Revival、AI Closet Organization。

### Phase 2：商业化
Wardrobe Gap、Pre-purchase Intelligence、Wardrobe-aware Commerce、CPS/B2B2C、闺蜜帮搭、Order Import。

## 十二条核心原则
1. Observation ≠ Truth
2. Behavior > Declaration
3. Personal Graph 是核心数据资产
4. PostgreSQL 是业务真相源
5. AI Provider 必须可替换
6. Celery 管执行，LangGraph 管决策
7. Modular Monolith 优先
8. Recognition Asset 与 Display Asset 分离
9. Product 与 WardrobeItem 分离
10. Existing Wardrobe First
11. Stable Spatial Memory First
12. 用户数据可追溯、可删除
13. 写操作边界严格，查询可以受控同步
14. 不同模型和不同维度的 Embedding 绝对不能混合计算
