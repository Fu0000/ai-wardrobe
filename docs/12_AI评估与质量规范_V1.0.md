# AI Wardrobe AI Evaluation & Quality Specification V1.0

## 一、评估维度

### Style Diagnosis Quality
- 评分准确性：与人类专业评审的一致率
- 问题识别：Primary Issue 命中率
- 建议可操作性：改善建议是否可执行
- 场景适配：不同 Occasion 的诊断差异化

### Optimization Fidelity
- Critic First-pass Rate：AI 自检首次通过率（Target ≥ 80%）
- 身份保持：优化后人物是否保持一致
- 服装保真：保留的衣物是否变形、变色
- 最小修改原则：是否做到了最少修改达到最大改善
- 异常检测：是否产生不合理的视觉瑕疵

### Entity Resolution Quality
- 同衣合并正确率（同一件衣服不同照片识别为同一实体）
- 误合并率（不同衣服错误合并，Target ≤ 2%）
- 未合并率（应该合并但未合并）
- 解决方案：High Confidence 自动 Resolve，其余走用户确认

### Display Asset Fidelity
- 颜色一致性：与原始衣物颜色差异
- Logo/图案保持：是否改变品牌标识
- 结构保持：衣物形状是否变形
- 锚点准确性：Anchor Point 是否正确定位
- 透明背景质量：边缘是否干净

### Try-On Quality（P1+）
- 身份保持：面部特征不变
- 服装融合：服装与人体自然贴合
- 无意外修改：不改变背景、不改变其他衣物

## 二、评估方法

### Golden Dataset
每个评估维度建立 Golden Dataset：
- Style Diagnosis：50+ 张不同场景、体型、光线的标注样本
- Entity Resolution：30+ 组同衣不同照片 + 易混淆相似款
- Display Asset：20+ 件不同类目的标注样本
- 数据集随产品迭代持续扩充

### MVP Release Dataset 准入

- Style Diagnosis 与 Style Optimization 的 `validation` Split 各不少于 50 条，且
  `sample_id` 唯一、数据集版本单一、资产为私有引用、授权记录引用有效；
- Diagnosis 覆盖校园、通勤、约会、面试、旅行和日常休闲，体型、肤色、光线、角度、
  背景复杂度均有完整标签且每维度至少两个取值；
- Diagnosis 至少包含 10 条低质/不合格输入与 5 条 Prompt Injection 样本；
- Optimization 同时覆盖正常结果，以及身份、身体、背景、姿势、未提及衣物和视觉异常
  六类刻意构造 Bad Case；预期拒绝结果不得曾展示给用户；
- Release Bundle 在 Provider 调用前校验以上合同，失败时原子拒绝且不得在报告中输出
  样本 ID、授权引用、对象地址或签名 URL。标准标签与命令以 `evals/README.md` 为准。
- Release Bundle 同时携带 Diagnosis/Optimization 双人盲评记录；每个 Validation
  样本至少两名匿名评审者，分歧样本需第三方仲裁。Diagnosis 评审绑定本次
  Model/Prompt/Schema 且通过率不低于 95%、维度均分不低于 4.0；Optimization 评审
  绑定生产图片模型，人工 PASS/REJECT 与 Failure Dimension 必须和 Manifest 一致。

### Automated Evaluator
- Critic Model：AI 自检评估（Diagnosis、Optimization）
- Schema Validation：结构化输出格式校验
- Visual Metrics：SSIM、LPIPS 等图像质量指标（Display Asset、Try-On）
- Attribute Matching：结构化属性与 Ground Truth 比对

### Human Review
- 每个模型版本上线前进行人工抽样评审
- 评审样本量：≥ 20 例/维度
- 评审人：产品团队 + 时尚领域顾问

### Regression Testing
- 每次模型/Prompt 版本更新前，在 Golden Dataset 上运行回归测试
- 与上一版本的指标对比，退化超过阈值则阻断发布

## 三、Release Gate

| 维度 | Release Gate | Target |
|:---|:---|:---|
| Diagnosis Success Rate | ≥ 95% | ≥ 98% |
| Critic First-pass | ≥ 75% | ≥ 85% |
| Entity Resolution 误合并 | ≤ 3% | ≤ 1% |
| Display Asset QA Pass | ≥ 90% | ≥ 95% |
| Regression vs Previous | 无显著退化 | 所有指标持平或改善 |

## 四、Model Release 流程
1. Golden Dataset 回归测试
2. Shadow Eval（生产流量镜像）
3. Human Review 抽样
4. 10% Canary + Model Release Guardrail 监控
5. 50% → 100% 灰度
6. 全程记录 model_version / prompt_version / schema_version

## 五、持续改进
- 每个 Sprint 收集用户反馈中的 AI 质量问题
- 将典型 Bad Case 加入 Golden Dataset
- 每月更新评估基线
