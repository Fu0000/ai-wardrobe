# AI Wardrobe 术语表与数据字典 V1.0

## 一、Domain Glossary（产品领域术语）

| 术语 | 英文 | 定义 | 所在文档 |
|:---|:---|:---|:---|
| 观察 | Observation | 对一件衣物的一次感知记录（来自照片、链接等），不等于事实 | DDD §5 |
| 证据 | Evidence | 支撑某个属性值的具体来源和置信度 | DDD §6 |
| 衣物实体 | WardrobeItem | 用户现实中拥有的一件具体物品，不等于 Product | DDD §4 |
| 商品 | Product | 电商平台上的标准化商品，与 WardrobeItem 解耦 | DDD §7 |
| 穿搭方案 | Outfit | AI 为用户生成的一套搭配方案 | PRD §九 |
| 穿搭记录 | Look | 用户选择的一套具体穿搭（可能来自 Outfit 或自选） | PRD §九 |
| 穿着事件 | WearEvent | 用户真实穿着某套 Look 的记录 | DDD §10 |
| 偏好信号 | PreferenceSignal | 从用户行为中提取的风格偏好维度和权重 | DDD §11 |
| 核心度评分 | Essential Score | 综合穿着频率、搭配广度、场景覆盖等计算的单品重要性 | DDD §12 |
| 衣橱缺口 | Wardrobe Gap | 用户现有衣橱无法覆盖的真实场景需求 | PRD §十五 |
| 数字孪生 | Garment Digital Twin | 一件真实衣物的完整数字表示（多次观察 + 证据 + 历史） | PRD §八 |
| 个人图谱 | Personal Graph | 包含 Garment/Style/Context/Decision/Commerce 五个子图 | DDD §2 |
| 渐进确认 | Progressive Confirmation | 只询问 AI 不确定且影响决策的属性，每次最多 1～3 个 | PRD §九 |

## 二、Technical Dictionary（技术术语）

| 术语 | 英文 | 定义 | 所在文档 |
|:---|:---|:---|:---|
| 场景快照 | Scene Snapshot | 后端将 Layout + Display Assets 渲染合成的一张完整衣橱图片 | TDD §十四 |
| 展示资产 | Display Asset | 标准化的透明背景商品展示图，包含画布、锚点、Content Bounds | DDD §13 |
| 识别资产 | Recognition Asset | 用于 AI 识别的原始裁切图，与 Display Asset 分离 | ADR §8 |
| 热区 | Hotspot | 前端覆盖在 Scene Snapshot 上的不可见交互区域 | TDD §十五 |
| 点击命中 | Hit Testing | 根据 hit_region、z_index、visual_center 计算用户点击命中哪件物品 | TDD §十五 |
| 视觉令牌 | Visual Token | DCVS 中用于表达衣物状态的统一视觉元素（吊牌、星星、气泡等） | UI-UX Design |
| 发件箱 | Outbox | Transactional Outbox 模式，业务数据与事件同事务写入 | TDD §七 |
| AI 调用 | AIInvocation | 一次真实的 AI Provider API 调用记录 | DDD §17 |
| 生成任务 | GenerationJob | 用户层的异步 AI 任务，可能包含多次 AIInvocation | DDD §17 |
| 可视化模块 | visualization/ | DCVS 业务域：决定"展示什么"（Scene/Zone/Slot/Layout） | TDD §三 |
| 渲染模块 | scene_rendering/ | 渲染基础设施：决定"怎么渲染成图"（Layout + Assets → Snapshot） | TDD §三 |
| 数字衣橱 | DCVS | Digital Closet Visualization System 的完整系统简称 | UI-UX Design |
| 版本化缓存 | Versioned Cache | 按 wardrobeVersion 等业务版本号管理缓存失效 | TDD §十六 |
| 配额 | Quota | 用户使用限额，防止成本失控 | DDD §20 |
| 限流 | Rate Limiting | API 请求频率限制，防止攻击 | API §十七 |
| 信用账本 | Credit Ledger | 付费 Credits 的 RESERVE/COMMIT/RELEASE 事务记录 | DDD §20 |
