# AI Wardrobe 里程碑与验收标准 V1.1

## 验收分类
- **Release Gate**：必须满足，否则不发布。
- **Target**：希望满足，通过真实测试校准。
- **Business Metric**：测试后决定基线。

## M0：工程基线
小程序登录、API、DB、Redis、COS、CI/CD、Staging、日志追踪全部可用。
Release Gate：Staging 环境全链路可用、备份恢复演练通过、Rate Limiting 就位。

对应：P0a（Epic 1-4, 8）。

## M1：AI Instant Experience
完成上传、Diagnosis、Optimization、Before/After。

Release Gate：
- Diagnosis Success Rate ≥ 95%
- P95 < 30 秒
- 无数据丢失
- Job 失败时正确展示用户友好提示并自动释放 Credits

Target：
- P90 < 20 秒
- Critic First-pass ≥ 80%

Business Metric：
- Optimization Click Rate
- Share Rate

对应：P0b（Epic 5-7）。

## M2：Growth Loop
完成 Share、SceneCode、A/B Vote。
Release Gate：来源可归因、好友可参与、新用户可继续体验。
Target：分享链路从生成到好友可见 ≤ 3 秒。

对应：P0b（Epic 7-8）。

## Hardening Gate
P0 blocker bug = 0，Prompt Version 化，Migration 审核，成本复盘。

## M3：Wardrobe Activation
完成照片入库、商品链接入库、Product Snapshot、WardrobeItem、Progressive Confirmation、Resolution。

Release Gate：
- 用户无需长表单建立 5 件衣物
- 解析失败可截图降级
- 同衣物可合并
- Supported Source Success Rate ≥ 90%
- Fallback Completion Rate ≥ 80%
- Entity Resolution 误合并率 ≤ 2%

对应：P0.5（Epic 9-10）。

## M4：Visual Shoe Wall
完成 5+ 鞋解锁、Display Asset、Scene Snapshot、Hotspot、Detail。

Release Gate：
- 低端设备（红米 Note 系列）Scene Snapshot 加载 ≤ 2 秒，无闪退
- Hotspot 命中正确率 ≥ 95%
- 位置稳定
- 资产失败可降级

对应：P0.5（Epic 11-12）。

## M5：Personal Stylist
完成 Outfit、Look、WearEvent、PreferenceSignal。

Release Gate：
- Outfit 生成仅使用 AVAILABLE 衣物，正确率 100%
- 选择和真实穿着可记录
- 偏好可更新

对应：P1（Epic 13-17）。

## M6：Retention Loop
Laundry、Weekly Planning、Old Clothes Revival、AI View。
Release Gate：待洗不被推荐，闲置可唤醒。

对应：P1.5。

## M7：Commercial Validation
Purchase Intelligence、Wardrobe Gap、Recommendation、Product Try-On。
Release Gate：Existing Wardrobe First、理由可解释、商业漏斗可追踪。

对应：Phase 2。

## 里程碑未通过处理
- **Blocker**：核心指标未达标，阻断下一里程碑，延期 1 个 Sprint 集中修复。
- **Conditional Go**：允许继续，但有明确 Deadline 偿还。
- **Accepted Debt**：不影响核心假设，进入 Backlog。
- 连续 2 个核心 Milestone 未通过 → 触发 Product + Architecture + Resource Review（问题可能来自模型能力、产品价值或资源不足，不只是架构）。

## 项目级成功条件
A 有首次价值。
B 用户愿意建库。
C 第二周仍主动使用。
D 出现真实付费。
E 商业建议不被理解为纯广告。
