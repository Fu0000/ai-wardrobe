# AI Wardrobe 成本预算与资源规划 V1.0

## 一、Unit Economics
核心指标：
- Cost per Diagnosis：单次穿搭诊断的 AI API + 计算成本
- Cost per Optimization：单次 Before/After 图片生成成本
- Cost per Try-On：单次虚拟试穿成本
- Cost per Active User：月活用户平均成本
- Cost per Paid User：付费用户平均成本

以上数据需在 P0b 结束后通过真实调用统计得出基线。

## 二、基础设施成本估算

### 腾讯云
- CVM：API Server + Worker（按 P0 配置 2～4 台）
- Managed PostgreSQL 18
- Managed Redis
- COS 对象存储 + CDN
- CLB 负载均衡
- CLS 日志服务

### AI API 调用
按 Provider 和 Task 分别核算：
- Vision Analysis（诊断）
- Image Generation/Edit（优化、Try-On）
- Embedding（语义/视觉）
- Background Removal（Display Asset）

## 四、成本控制手段
- Quota 系统：免费用户每日/每月使用次数限制
- Credits 系统：付费用户按 Ledger 模式管理
- AI Provider 路由：根据任务类型和成本要求选择 Provider
- Display Asset 复用：Scene Snapshot 避免重复生成
- 图片质量档位：Thumbnail / Detail 双分辨率

## 五、定价决策依赖
本文档产出的 Unit Economics 将直接决定：
- 免费额度设定
- Pro 会员定价
- Credits 购买价格
- AI Provider 路由策略
- 图片质量分级策略
